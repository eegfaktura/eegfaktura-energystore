# eegfaktura-energystore: known errors

Source: `known-errors.md`, checked against the code at `07d2457` (2026-10-02). The `#` column is the row number in `known-errors.md`. This list leaves out the build, CI and test-environment items (#1–#10, #12, #13, #47) and the critical errors, which are kept privately.

Severity:
- **High:** wrong billing data or results, a broken login, or a request that panics.
- **Medium:** limited impact, a suspected issue not yet reproduced, or hardening.
- **Low:** minor issues, dead code or code style.
